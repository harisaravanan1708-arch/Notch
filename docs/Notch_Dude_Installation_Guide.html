★ Product Overview & Architecture

Notch Dude is an executive-grade Dynamic Island & Top Notch productivity suite developed for Windows 10 and Windows 11. It docks discreetly at the top edge of the primary monitor, providing background YouTube Music streaming, real-time hardware telemetry, timer alerts, a quick file shelf, and intelligent clipboard history.

Zero External Dependencies: Notch Dude is packaged as an independent, standalone Windows installation bundle. Deploying to any new PC requires no pre-installed runtimes (No Node.js, Python, or Git required).
1 Step 1: Obtain the Standalone Installer Executable File Size: ~126 MB

The compiled production installer is located in the official release directory:

release/Notch Dude Setup 1.0.0.exe

To transfer this single installer to any destination PC or laptop, use one of the standard distribution methods below:

💾 Method A: USB Flash Storage (Recommended)
Copy Notch Dude Setup 1.0.0.exe directly onto an external USB drive and paste it onto the target computer. Fully offline.
☁️ Method B: Cloud Storage (Drive / OneDrive)
Upload the installer to Google Drive, Dropbox, or OneDrive. Generate a secure download link and download it on the target workstation.
💬 Method C: Direct Document Transfer
Send the executable via Telegram or WhatsApp Web using the "Document" attachment mode to preserve original binary integrity.
🌐 Method D: Local Network Share
Transfer over the local subnet via Windows File Sharing (SMB) or Nearby Share between devices connected to the same network.
Deployment Notice: Transfer only the single .exe installer file. Do not copy source repositories, node_modules, or development artifacts.
2 Step 2: Launch the Installer on the Target Machine

Once the installer file is located on the destination machine:

  1. Locate Notch Dude Setup 1.0.0.exe in your Downloads or Desktop directory.
  2. Double-click the executable to launch the installation routine.

? Frequently Asked Questions & Support

Q: Does installation require active internet connectivity?
A: No. The installer is fully offline. Internet access is only utilized during runtime to stream YouTube Music tracks.
Q: How do I configure Notch Dude to run automatically on Windows startup?
A: Press Win + R, enter shell:startup, and paste a shortcut of Notch Dude into that folder.
